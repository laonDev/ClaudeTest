# 🎮 HTML5 스도쿠 게임

HTML5로 만든 완전 기능 스도쿠 게임입니다. 브라우저에서 바로 실행할 수 있습니다.

## 🎯 특징

- **세 가지 난이도**: 쉬움, 중간, 어려움
- **자동 퍼즐 생성**: 매번 새로운 퍼즐
- **실시간 유효성 검사**: 잘못된 입력을 즉시 표시
- **타이머**: 게임 시간 추적
- **실수 카운터**: 최대 3번의 실수 허용
- **힌트 기능**: 막힐 때 도움받기
- **숫자 패드**: 마우스나 키보드로 입력
- **관련 셀 하이라이트**: 선택한 셀과 관련된 행, 열, 블록 강조
- **반응형 디자인**: 모바일 기기에서도 작동

## 🚀 실행 방법

1. `sudoku.html` 파일을 웹 브라우저로 열기
2. 또는 로컬 서버로 실행:
   ```bash
   python -m http.server 8000
   # 브라우저에서 http://localhost:8000/sudoku.html 접속
   ```

## 🎲 게임 방법

1. **셀 선택**: 빈 셀을 클릭하여 선택
2. **숫자 입력**:
   - 화면의 숫자 패드 클릭
   - 또는 키보드로 1-9 입력
   - Backspace/Delete로 숫자 삭제
3. **난이도 변경**: 하단의 난이도 버튼 클릭
4. **게임 컨트롤**:
   - **새 게임**: 새로운 퍼즐 시작
   - **정답 확인**: 현재 진행 상황 확인
   - **힌트**: 무작위 셀에 정답 표시
   - **초기화**: 초기 상태로 돌아가기

## 🎨 게임 규칙

스도쿠는 9x9 그리드에 1부터 9까지의 숫자를 채우는 퍼즐입니다:

- 각 행에는 1-9의 숫자가 한 번씩만
- 각 열에는 1-9의 숫자가 한 번씩만
- 각 3x3 블록에는 1-9의 숫자가 한 번씩만

## 💻 기술 스택

- HTML5
- CSS3 (Grid, Flexbox, Animations)
- Vanilla JavaScript (ES6+)

## 📝 구현 기능

- **퍼즐 생성 알고리즘**: 백트래킹을 이용한 완전한 스도쿠 생성
- **유효성 검사**: 실시간으로 규칙 위반 감지
- **UI/UX**: 직관적인 인터페이스와 시각적 피드백
- **게임 상태 관리**: 타이머, 실수 카운터, 난이도 설정

## 🎯 난이도별 힌트 개수

- **쉬움**: 40개 제거 (41개 힌트)
- **중간**: 50개 제거 (31개 힌트)
- **어려움**: 60개 제거 (21개 힌트)
